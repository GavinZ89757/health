      记录医嘱/笔记

        备份（推荐：复制文字备份）

        所有记录只保存在这台手机的这个浏览器里，不会上传到任何服务器。清除浏览器数据、换浏览器或换手机都会丢失记录，请定期备份。

        复制后粘贴到微信"文件传输助手"或手机"便签"里发送/保存，就算备份好了。包含标志物、治疗、医嘱全部文字记录；报告照片和附件不包含，请保留原件（相册照片、医院给的文件）。

        浏览器不允许自动复制。请长按下面的框 → "全选" → "复制"，复制好后点"我已复制"。

        从复制的内容恢复

        恢复是"合并"：只添加本机没有的记录，不会覆盖或删除现有记录。

        完整备份文件（含报告）

        把全部记录和报告文件打包成一个文件。小米浏览器可能存不下来：点完后请到"文件管理 → 下载"里确认有"康复记录备份_日期.json"。找不到就说明不支持，请用上面的复制备份。

        关于本机存储

        添加到桌面（小米浏览器）

        1. 用小米浏览器打开本页网址（必须是 https 网址，不能是手机里的文件）。
        2. 点底部菜单（☰ 或"三条横线"）→ "添加到桌面"或"添加至 → 桌面"。
        3. 桌面没出现图标：设置 → 应用设置 → 应用管理 → 浏览器 → 权限 → 打开"桌面快捷方式"，再添加一次。
        4. 以后都从这个图标或同一个浏览器打开。换浏览器打开，看不到这里的记录。

        清空数据

        会要求两次确认。建议先导出备份。
